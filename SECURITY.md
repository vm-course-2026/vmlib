# Политика безопасности

## Поддерживаемые версии

Исправления безопасности выпускаются для последней опубликованной minor-ветки.
Для серии 1.1 поддерживается последняя версия `1.1.x`.

## Как сообщить об уязвимости

Не создавайте публичный issue и не раскрывайте детали до согласованной
публикации. Откройте приватный отчёт через
[GitHub Private Vulnerability Reporting](https://github.com/vm-course-2026/vmlib/security/advisories/new).

Укажите затронутую версию, минимальный способ воспроизведения, возможное
влияние и известный обходной путь. Не прикладывайте настоящие токены,
персональные данные и закрытые исходники. Сопровождающие подтвердят получение,
проверят воспроизведение и согласуют исправление и срок раскрытия в приватном
security advisory.

## Граница ответственности

`vmlib` — библиотека измерений и визуализации, а не песочница. Она не должна
служить границей безопасности для недоверенного Python-кода. Такой код следует
запускать в отдельной одноразовой среде без сети, секретов и доступа к данным
основной машины.
